# Релиз: Фильтрация по формату работы и уровню должности в LinkedIn

**Дата:** 1 апреля 2026

---

## Что изменилось и почему

Поиск вакансий через LinkedIn стал точнее. Раньше не было возможности сразу указать, что нужны только удалённые, гибридные или офисные вакансии — приходилось вручную отсеивать нерелевантные результаты. Также нельзя было отфильтровать вакансии по уровню должности. Оба ограничения устранены.

---

## Изменения в деталях

### 1. Фильтр по формату работы: Remote / Hybrid / Onsite

Теперь при поиске вакансий можно указать конкретный формат работы. LinkedIn гарантирует точность этого фильтра — в результатах будут только вакансии выбранного формата.

Доступные значения:
- **remote** — полностью удалённая работа
- **hybrid** — смешанный формат (частично в офисе, частично удалённо)
- **onsite** — только работа в офисе

Каждая вакансия в результатах теперь содержит поле **work_format** с одним из этих значений, а также поле **is_remote** (да/нет).

**Пример:** запрос "Product Designer, remote" вернёт только удалённые вакансии, и каждая из них будет помечена `work_format = remote`.

> Важно: для каждого формата нужно делать отдельный запрос. Нельзя запросить remote и hybrid одновременно — иначе невозможно гарантировать, какой именно формат у конкретной вакансии.

---

### 2. Фильтр по уровню должности (Seniority)

Теперь можно ограничить поиск определёнными уровнями должности. Это убирает из результатов вакансии, которые явно не подходят по опыту.

Доступные уровни:

| Уровень | Кому соответствует |
|---|---|
| **internship** | Стажёры, без опыта |
| **entry** | Junior, 0–2 года опыта |
| **associate** | Переход Junior → Middle, 2–4 года |
| **mid_senior** | Middle и Senior, 4–8 лет опыта |
| **director** | Директора, руководители направлений |
| **executive** | C-level, VP и выше |

Можно указать несколько уровней сразу — например, `mid_senior` и `director` одновременно.

---

### 3. Исправлена ошибка с фильтром удалённой работы

Ранее при запросе `is_remote=True` система ошибочно запрашивала у LinkedIn **гибридные** вакансии вместо удалённых. Это было незаметно, но приводило к тому, что в результатах появлялись офисно-гибридные вакансии вместо полностью удалённых. Ошибка исправлена.

---

## Итог

- Поиск вакансий теперь можно точно ограничить по формату работы: только remote, только hybrid или только onsite
- Каждая найденная вакансия содержит явное поле с форматом работы — не нужно угадывать по описанию
- Можно фильтровать по уровню должности и не получать стажёрские вакансии в ответ на запрос Senior-позиций
- Исправлена старая ошибка: `is_remote=True` теперь действительно возвращает удалённые вакансии
